# P1-02: Compare three interaction concepts and deliver C1

| Field | Value |
| --- | --- |
| Phase | 1 |
| Type | Experiment |
| Status | Draft |
| Owner | Unassigned |
| Required roles | Product researcher and designer |
| Decision targets | Q-12 |

## Outcome

Test asset-first, intent-first and contextual concepts before Phase 2 fixes the account model.

## Blocked by

- [P1-01: Choose the audience and supported onboarding conditions](p1-01.md)

## Acceptance criteria

- [ ] Prepare distinct prototypes for all three concepts. Include receiving, chain choice, approval comprehension and finding recovery or exit.
- [ ] Define participant selection, tasks, scoring and sample size before sessions. Use the same conditions across concepts.
- [ ] Record task completion, comprehension errors and accessibility observations. Keep anonymized evidence and consent records in appropriate storage.
- [ ] Choose a concept with reasons and rejected alternatives. Record uncertainty instead of averaging the concepts into one design.
- [ ] Deliver C1 with account-model requirements, terminology and unresolved custody-dependent UX questions. Do not wait for final recovery usability results to deliver C1.

## Evidence

Prototype references, research protocol, anonymized results and the accepted C1 handover.

## Failure or deferral

If no concept meets the declared criteria, revise and retest. Phase 2 cannot fix the account model without C1.
