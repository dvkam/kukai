## Outcome

Exercise the selected custody design through its real device and browser interfaces using test keys.

## Acceptance criteria

- [ ] Integrate the prototype Rust core through Swift bindings and WebAssembly. Keep this work outside the production wallet flows.
- [ ] Test enroll, sign, lock, logout, restore, biometric changes and device replacement. Check that traces and UI state contain no shares or recovery factors.
- [ ] Race revocation with each protocol's irreversible release. Test concurrent sessions, repeated recovery objections and backups without nonce or presignature state.
- [ ] Run malicious-web and compromised-service cases separately and together. Confirm that failures match the selected Q-01 design and named residuals.
- [ ] Replay the recorded protocol events against the specification. Include optional key types only after their experiment is eligible for admission.

## Evidence

Cross-platform conformance results, physical-device evidence, adversarial traces and trace-validation reports.

## Failure or deferral

Unexpected authority or secret exposure blocks G3. Reopen Phase 2 decisions contradicted by the experiment.
