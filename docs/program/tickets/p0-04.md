# P0-04: Fund the work and reserve independent review

| Field | Value |
| --- | --- |
| Phase | 0 |
| Type | Decision |
| Status | Draft |
| Owner | Unassigned |
| Required roles | Project owner, engineering lead and audit coordinator |
| Decision targets | Q-24 |

## Outcome

Match the release scope to named people, equipment, operating cost and independent review capacity.

## Blocked by

- [P0-01: Record the charter and assign the open decisions](p0-01.md)
- [P0-03: Verify cryptographic libraries and development toolchains](p0-03.md)

## Acceptance criteria

- [ ] Name the people responsible for product research, cryptography, formal methods, iOS, web, operations and security review. Identify roles without an owner.
- [ ] Estimate the work and cost for each phase from the ticket scope. Include recruitment, devices, macOS runners, signers, nodes, data and media services.
- [ ] Obtain funding approval and booked independent review capacity. Record scope, reviewer independence, dates and exclusions without confidential commercial details in public files.
- [ ] Set experiment timeboxes and decision dates. Assign the gates to reviewers other than the experiment authors where the plan requires independence.
- [ ] Cut optional scope if capacity is insufficient. Preserve the release minimum unless the owner approves a new decision.

## Evidence

A named capacity plan, budget decision, resource access evidence and review booking references.

## Failure or deferral

Unfunded or unassigned required work blocks G0. Do not treat an intention to book an audit as a booking.
