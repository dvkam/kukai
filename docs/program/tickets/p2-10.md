Check the selected architecture against the frozen mandatory properties and its named trust assumptions.

## Acceptance criteria

- [ ] Model the section 6 state machines in TLA+ and the security protocols in Tamarin. Record exact bounds, fairness, abstraction and trusted code.
- [ ] Prove each non-waivable obligation with the selected tool. Keep implementation proof obligations for Phase 3 separate from architecture-model results.
- [ ] Cross-check the protocol model with ProVerif. Investigate concrete disagreements; record timeouts as unverified results.
- [ ] Break each trust assumption in a separate attacker case. Compare the observed behavior with its named residual risk. An unexplained result blocks the gate.
- [ ] Apply deliberate mutations and require the checks to catch them. Define the mapping from prototype protocol events to TLA+ actions and validate recorded experiment traces.
- [ ] Obtain independent model review. Record exceptions only for eligible properties, with owner acceptance, residual risk and a closing date.

## Evidence

Model files, reproducible commands, proof reports, counterexamples, mutation results, trace mappings and independent review.

## Failure or deferral

An unproved non-waivable property or an in-assumption counterexample blocks G2. Logged trace conformance cannot replace a missing proof.
