# P2-11: Receive legal advice for the selected custody design

| Field | Value |
| --- | --- |
| Phase | 2 |
| Type | Decision |
| Status | Draft |
| Owner | Unassigned |
| Required roles | Project owner and qualified legal reviewer |
| Decision targets | Q-15 |

## Outcome

Resolve the legal question using the actual custody and recovery design selected in Phase 2.

## Blocked by

- [P2-06: Choose custody and enforceable web exposure controls](p2-06.md)
- [P0-05: Prepare custody legal questions and platform constraints](p0-05.md)

## Acceptance criteria

- [ ] Update counsel with the accepted custody decision, exit path, signer role, recovery policy and intended markets.
- [ ] Receive the written opinion and record its scope, assumptions, limitations and required operational changes.
- [ ] Map required changes to decisions or blockers. Keep confidential advice outside public issue bodies; link an access-controlled evidence reference where needed.
- [ ] Have the owner record whether the proposed launch structure can proceed. Reopen custody if the opinion contradicts its assumptions.

## Evidence

A receipt reference, a publishable conclusion approved by the owner and any required follow-up decisions.

## Failure or deferral

No opinion or unresolved required change blocks G2. An engineering assessment cannot substitute for counsel.
